# Swagweld

This repository hosts an application to bundle multiple swagger.yaml files into one big api specification.

## Coding Guidelines

- Keep it simple! Don't overengineer or overacomplish. The least complex solution is the most scalable and maintainable. The smallest diff that achieves the wanted result is the best one.
- Use test driven development (red, green, refactor) for code changes
